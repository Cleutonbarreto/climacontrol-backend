# ClimaControl Backend

API REST desenvolvida para gerenciamento de assistência técnica de climatização.

## Tecnologias

- Java
- Spring Boot
- Spring Security
- PostgreSQL
- Docker
- Maven

## Funcionalidades

- Cadastro de clientes
- Controle de equipamentos
- Ordens de serviço
- Autenticação de usuários
- API REST

## Arquitetura

O projeto segue arquitetura em camadas:

- Controller
- Service
- Repository
- DTO
- Entity

## Objetivo

O ClimaControl foi criado para modernizar e organizar processos de assistência técnica e controle operacional.

## Status

Projeto em desenvolvimento.
